# Demo video script (about 4 minutes)

**0:00–0:25 · Start** (dashboard on screen)
"People across India ask for water, toilets, electricity and schools, in many languages. Those requests are scattered and
never meet the government's own data. JanVaani brings them together using Google Gemini and real NFHS-5 data."

**0:25–1:30 · Citizen portal** (`/submit`)
1. Tap the mic and speak in Hindi or Telugu about a real-sounding problem, e.g. no toilets in the village.
2. Submit. Show: language detected, what was heard, English translation, category and scheme, urgency, district.
3. The reply plays in the same language. Point to the ticket number.
4. Show "N citizens have reported this same issue".

**1:30–2:50 · Planner dashboard** (`/`)
1. Top numbers: 705 districts, 34 states. Point out "live" vs "sample" tags in the request feed.
2. Map: hotspots and dashed "emerging" circles.
3. Ranking: open a top project (e.g. Saran sanitation). Show NFHS-5 coverage 37%, Census population, people without the service.
4. Click **Generate brief with Gemini** and read the recommendation.
5. Move the **Gap (NFHS-5)** slider: the ranking changes instantly.

**2:50–3:30 · Ask a question**
Type "Which 5 districts have the lowest sanitation coverage?" Show the answer (Puruliya 29.2%, …) and the SQL query.

**3:30–4:00 · Close**
Architecture slide. "Real government data, every citizen's voice, clear reasons for every recommendation. That's JanVaani."

Tips: record in Chrome at 1280×720, make sure the badge says "Gemini live", and submit one request before recording.
